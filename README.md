# Havenly Real Estate

A responsive, polished property-discovery website built with Next.js, TypeScript, and Tailwind CSS.

## Included

- Auto-advancing hero slider with manual controls
- Responsive desktop/mobile navigation and reusable footer
- Searchable and filterable property collection
- Dynamic individual property pages with gallery, features, related listings, and enquiry form
- About, contact, and custom 404 pages
- Sample property data and responsive image optimization via `next/image`

## Run locally

1. Open a terminal in the `realestateapp` folder.
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Visit `http://localhost:3000`

For a production check, run `npm run build` and then `npm run start`.

## Notes

The property photography uses remote Unsplash images. Replace the URLs in `data/properties.ts` with licensed production imagery before publishing a commercial site.
